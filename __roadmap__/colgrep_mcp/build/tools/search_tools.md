# Search Tools

**Goal**: Implement the three agent-facing search tools — `search`, `find_files`, `expand` — with compact text output under a token budget and full structured output, on top of `ColgrepAdapter`.
**Pre-conditions**:
- [ ] `build/colgrep_adapter` merged (`ColgrepAdapter.search` works against the fake binary)
- [ ] `server/colgrep_mcp/tools_search.py` stub with `register(mcp)` exists
**Success Gates**:
- ⬜ [run] `cd server && uv run pytest -q tests/test_tools_search.py` passes
- ⬜ [run] Through `Client(build())`, `search` returns `structured_content` validating as `SearchResult`, and its text content is ≤ `COLGREP_MCP_TEXT_BUDGET` chars even with a 2 000-hit fixture
- ⬜ [run] `expand` on a `hit_id` from a `search` result returns the exact source lines `[line, end_line]` of the file; an id for a missing file yields a per-unit `error`, not a tool error
- ⬜ [static] All three tools carry `ToolAnnotations(read_only_hint=True, idempotent_hint=True, open_world_hint=False)` and a `title`
**References**: [R01 §Tools](../../../../__reports__/colgrep_mcp/00-architecture_v0.md) — arguments, annotations; [R01 §Token-budget invariant](../../../../__reports__/colgrep_mcp/00-architecture_v0.md) — text shape and cap; [R01 §hit_id invariant](../../../../__reports__/colgrep_mcp/00-architecture_v0.md); [R05 D1, D5, D7](../../../../__reports__/colgrep_mcp/02-architecture_v1.md) — hits must be located via `locate_unit` (colgrep's line numbers are wrong), `limit=None` without `pattern` needs a note, `index_updated` comes from stderr; [R02 Tools table](../../../../__reports__/colgrep_mcp/01-findings_mcp_feature_matrix_v0.md) — structured output adopt-now, tool naming guidance

## Step 1: Shared helpers — path resolution, hit conversion, text rendering
**Goal**: Pure, unit-tested functions the three tools compose, kept out of the handlers so they can be tested without a client.
**Implementation Logic**:
In `tools_search.py` (or a small `_common.py` if `tools_index.py` will need the same path resolver — coordinate through R01: the resolver lives in `colgrep_mcp/paths.py` and BOTH tool modules import it; create `paths.py` here):
- `paths.py`: `resolve_paths(paths: list[str] | None, settings: Settings, roots: list[Path] | None) -> list[Path]` implementing the R01 resolution order (explicit → `settings.root` → first root → `Path.cwd()`), expanding `~`, resolving relative paths against the default root, raising `ToolError` listing any that do not exist; `default_root(settings, roots) -> tuple[Path, str]` returning the path and its source label (`argument|env|roots|cwd`).
- `hit_from_raw(raw: RawHit, snippet_lines: int, include_code: bool, file_cache: dict[str, str]) -> SearchHit`: reads the file once into `file_cache`, calls `colgrep_mcp.locate.locate_unit(file_text, code, reported_line, reported_end)` (R05 D1) to obtain `(line, end_line, verified)`, sets `location_verified`, builds `hit_id = f"{file}:{line}-{end_line}"` from the LOCATED lines, `snippet` = first `snippet_lines` lines of `unit.code` (None if code missing), `code` only when requested; tolerant of missing/None fields per R03's schema.
- `render_search_text(result: SearchResult, budget: int) -> tuple[str, bool]`: header line (`N hits for "query" [pattern] in paths — elapsed ms`), then per hit `file:line-end_line  score=0.00  unit_type name — signature` followed by the snippet indented two spaces; stop emitting hits when the next block would exceed `budget`, append `[K more hits in structured_content; call expand(hit_ids=[...]) for code]`; return `(text, was_capped)`. Also `render_files_text`.
Tests: `tests/test_paths.py`, `tests/test_render.py` (budget boundary: exactly at budget, one over; zero hits renders the `notes`).
**References**: [R01 §Path resolution invariant](../../../../__reports__/colgrep_mcp/00-architecture_v0.md)
**Deliverables**: `server/colgrep_mcp/paths.py` (`resolve_paths`, `default_root`), `server/colgrep_mcp/tools_search.py` (`hit_from_raw`, `render_search_text`, `render_files_text`), `server/tests/test_paths.py`, `server/tests/test_render.py`
**Consistency Checks**: `cd server && uv run pytest -q tests/test_paths.py tests/test_render.py` (expected: PASS)
**Commit**: `feat(search): add path resolution, hit conversion and budgeted text rendering`

## Step 2: Register `search`, `find_files`, `expand`
**Goal**: The tools an agent actually calls.
**Implementation Logic**:
`register(mcp)` defines three async functions decorated with `@mcp.tool(title=..., annotations=ToolAnnotations(read_only_hint=True, idempotent_hint=True, open_world_hint=False))`, each taking `ctx: Context` and returning `CallToolResult(content=[TextContent(...)], structured_content=model.model_dump())` (verified: MCPServer passes a returned `CallToolResult` through unchanged; `output_schema` is then not advertised — accepted, the docstring names the model). Argument docstrings/`Annotated[..., Field(description=...)]` must be short and precise (they are what the agent reads): e.g. `query: str` "Natural-language description of the behaviour you are looking for", `pattern: str | None` "Regex pre-filter (hybrid mode): only units whose text matches are ranked", `limit: int | None = 15` "Max hits; pass null for exhaustive", `snippet_lines: int = 6`, `include_code: bool = False`. Obtain the adapter via `get_adapter(ctx)` from `server.py`'s lifespan context (R01: `server_assembly` wires it; until then, construct `ColgrepAdapter(settings.binary, settings.timeout_s)` lazily from `Settings.from_env()` inside a module-level `_adapter()` helper that `server_assembly` will replace — leave a `# TODO(server_assembly)` marker). Wrap the adapter call: `ColgrepNotFound`→`ToolError` with install hint; `ColgrepFailed`→`ToolError` with stderr tail; `ColgrepTimeout`→`ToolError` suggesting `index_build`; zero hits → `notes`; `limit is None and pattern is None` → append the R05 D5 note; `index_updated = any("Building index" in l for l in stderr_lines)` (R05 D7). Emit `await ctx.warning(...)` when truncated; forward adapter stderr lines to `ctx.info`/`ctx.report_progress` through `on_stderr` (progress only when `parse_progress` returns a pair). `find_files`: run the same search (limit multiplied by 3, capped 300, when `limit` given) then group by file preserving best-score order → `FileResult`. `expand`: parse each id with a strict regex `^(.+):(\d+)-(\d+)$`, read lines `[line, end_line]` (1-based inclusive) with `errors="replace"`, truncate to `max_lines` with `truncated=True`; per-unit `error` for unreadable files; text content = concatenated fenced blocks labelled by `hit_id`.
Tests in `tests/test_tools_search.py` via `Client(build())` with the fake binary: search text+structured shape; `limit=None` omits `-k` (assert via a fake-binary argv echo: extend `fake_colgrep.py` to dump its argv to `$FAKE_COLGREP_ARGV_FILE` when set); pattern/include flags reach argv; find_files grouping; expand happy path against a temp file; expand missing file; ToolError on bad path; ToolError text on `FAKE_COLGREP_EXIT=2`.
**References**: [R01 §Error model](../../../../__reports__/colgrep_mcp/00-architecture_v0.md); [R03 §Observations](../../../../__reports__/colgrep_mcp/01-findings_colgrep_behaviour_v0.md) — zero-hit and bad-path behaviours to translate
**Deliverables**: `server/colgrep_mcp/tools_search.py` (`register`, tools `search`, `find_files`, `expand`, helper `_adapter`, `_translate_error`), `server/tests/test_tools_search.py`, `server/tests/fake_colgrep.py` (argv echo via `FAKE_COLGREP_ARGV_FILE`)
**Consistency Checks**: `cd server && uv run pytest -q tests/test_tools_search.py` (expected: PASS)
**Commit**: `feat(search): register search, find_files and expand tools with budgeted output`
